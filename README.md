# Playable Games — Sample Project (Base)

> **이 브랜치(`main`)는 기본 샘플 프로젝트입니다.**
> 새로운 게임 개발은 별도 브랜치에서 진행됩니다.

---

## 프로젝트 구조

| 브랜치 | 설명 |
|--------|------|
| `main` | **기본 샘플 프로젝트** (현재 브랜치) — 베이스라인 |
| `feature/hybrid-puzzle` | 하이브리드 퍼즐 플레이어블 게임 |

---

## 현재 프로젝트: AIX Snake

Unity 기반 Snake 게임 샘플입니다. 모든 신규 플레이어블 게임 브랜치의 출발점으로 사용됩니다.

### 요구 사항

- Unity 2022.x 이상
- .NET / C#

### 실행 방법

1. Unity Hub에서 `My project` 폴더를 열기
2. Play 모드로 실행

---

## 브랜치 전략

- `main`: 기본 프로젝트 (변경 최소화)
- `feature/<game-name>`: 각 플레이어블 게임별 독립 브랜치
